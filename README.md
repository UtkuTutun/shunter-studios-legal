# Shunter Studios legal

This repository holds the public legal documents for games by Shunter Studios. GitHub Pages publishes it as a small website.

It is a temporary home. When the Shunter Studios website is ready, the documents will move there.

## Versions

Each document shows its effective date and version at the top. Earlier versions stay in the history of this repository.

## Contact

Players can write to the developer email address shown on the game's Google Play and Steam store pages. To delete a Little Refinery account, use Menu > Account > Delete account in the game.
